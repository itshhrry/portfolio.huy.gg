What the work cost.

This is the Claude view of Sphere, the monitoring app I built for my own machines and workflow, exported from the running app and drawn by its own chart code. Every figure comes from my Claude Code session history: what each session cost, which models and effort levels carried the work, how often my prompts to each model show frustration, how close the work ran to the five-hour and weekly usage limits, and which tools and skills it ran through. The data is a snapshot taken November 18, 2026, and the range switch at the top right re-cuts every card from the last hour to all time.
